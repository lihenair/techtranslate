# 机器学习研究 Agent 为什么不过拟合？

原文链接：<https://www.amazon.science/blog/why-dont-machine-learning-research-agents-overfit>

原文作者：Martin Bertran Lopez、Aaron Roth

![文章头图](https://cdn.amazon.science/28/46/0121ba1e4b42be0c56e7560c9844/compressionmodels-03-16x9.png)

作者：[Martin Bertran Lopez](https://www.amazon.science/author/martin-bertran-lopez)、[Aaron Roth](https://www.amazon.science/author/aaron-roth)

发布于 2026 年 9 月 10 日。

**听的人懂的越多，你要发的消息就越短。专家 ML 工程师几句话就够；新手需要整本手册。**

新研究表明：AI agent 学到的是可压缩的数据模型，里面没有足够空间去记答案。

- ML 模型反复迭代改进之后，也不会在基准上过拟合（overfit）。这跟教科书唱反调：对着同一份留出数据评太多次，按理该过拟合。
- 对 ML 研究 agent 的实验表明，成功策略高度可压缩。把成功 agent 的策略挤过信息瓶颈（少到 16 个 token），一个没有记忆的新 agent 仍能复现原成绩——说明策略抓住了真实结构，不是把数据背下来了。
- 压缩既是解释，也是诊断工具。真正过拟合的策略过不了压缩测试：那些只对验证集有效的增益，一过瓶颈就消失。
- LLM 是很强的压缩解码器。它们带着大量世界知识，能从极短的专家速记提示还原整条 ML 管线——这也是理解它们为何这么能干的一条具体路径。

机器学习的核心是泛化，不是记忆。你把一堆训练样本交给学习算法，用它们拟合一个模型。目标不是在训练样本上表现好——那很容易，把答案背下来就行。目标是在从未见过的新样本上表现好。如果模型在训练数据上很好、在新鲜数据上很差，它其实什么都没学到；你只是骗过了自己。这种失败模式有个名字：过拟合。

上过入门统计或机器学习课的人都知道标准防御：留出一部分数据，拒绝在上面训练。实践里，这份留出数据扮演两个角色。验证集（validation set）是你在建模过程中反复看的——比较候选、调超参、决定下一步试什么。最终测试集（test set，或 holdout）理论上只在最后摸一次：训练过程从没见过它，所以上面的好成绩才是对野外新样本的合格代理。

> 机器学习的核心是泛化，不是记忆。

可「holdout」这个条件很要紧。代理保证成立的前提是：留出集真的没被看见。如果你在上面查成绩、据此改训练、再查、再改，一路追数字，它就不再是未见过的；它已经进了训练流程。做的次数够多，你也能过拟合它，就像过拟合训练集一样，于是你丢掉了对未见数据的代理。凡是你这样复用的留出集都成立，包括验证集——验证集天生就是拿来复用的。

## [机器学习核心的一个谜](#a-puzzle-at-the-heart-of-machine-learning)

真实的机器学习研究，长得**正好**像我们刚描述的那条迭代改进回路。所有人都拿少数几年不改的基准数据集衡量表现。研究社区在重复一个巨大的、分布式的循环：在基准上评模型，改训练流程，再评，发表，让下一组再挤出一点提升。

这正是教科书里那种对着留出集爬山、理应造成大规模过拟合的做法。到现在，排行榜早该堆满「基准上好看、别处平庸」的模型。

可事实不是这样。给那些被反复用过的旧基准另建全新测试集的研究发现：提升大体**会转移**——在新数据上，模型表现出跟旧基准上同样的增益。基准驱动的机器学习，违背教科书的预测，产出了快速而且大体**真实**的进步。为什么？

假说并不缺，但很难实证检验，因为实验的「被试」是整个人类研究社区。你没法重置一个领域、擦掉它的记忆，再在受控条件下把过去十年重跑一遍。

但我们可以做一件相近的事。现在已经有能干的、基于 LLM 的研究 agent，能自主跑人类社区跑的那种机器学习优化回路。它们同样在基准上爬山——而且有意思的是，它们似乎也不过拟合。差别在于：agent 不像研究社区，**可以**重置。你可以清掉它的记忆，精确控制它看见什么，再跑一遍实验。在最近的论文 [What fits (into few tokens) doesn't overfit: Compression and generalization in ML research agents](https://arxiv.org/abs/2606.11045) 里，我们正是这么做的——顺手给这个老谜题一个具体解释。

## [把奥卡姆剃刀写精确](#occams-razor-made-precise)

解释从一个很老的想法开始。奥卡姆剃刀（Occam's razor）说：在同样能解释数据的假设里，更简单的那个更可能是对的。这套直觉有精确的数学形式，整篇文章都站在它上面。

假设你能用很少的 bit 描述你的假设——你的模型、你的策略——远少于把训练数据背下来所需的 bit。如果这个紧凑假设在训练数据上表现很好，它在新数据上也必须表现很好。

[原文短视频](https://cdn.amazon.science/72/eb/d021ebfc445d8f4acd2fe2ac211c/compressionmodels-01-1x1.mp4)

![奥卡姆剃刀：同样能解释数据的假设里，能用更少 bit 描述的那个更可能泛化](https://raw.githubusercontent.com/lihenair/techtranslate/master/assets/Why-dont-machine-learning-research-agents-overfit/video-1.gif)

奥卡姆剃刀的形式化：在同样能解释数据的假设里，更简单的那个——能用更少 bit 描述的那个——更可能泛化到新样本。

推理走的是计数论证。短描述本来就不多，因为短字符串本来就不多。候选假设越少，其中某一个靠运气在训练集上骗过你的可能性就越小——即便你用训练集引导了搜索。

换一种直觉：如果你的压缩描述小到没法偷偷记下训练数据，那么它在训练数据上表现好，就不可能是因为把答案背下来了——它没地方背。它必须是抓住了数据结构里的真东西。短描述没法作弊，因为没有空间。

这里有一个很好看的假说：**成功的机器学习策略高度可压缩。** 研究者在一个项目里可能盯过几千个基准分数，但最后活下来的策略通常是一份很短的熟悉选择清单——一个架构家族、一个优化器、一个学习率日程、一套数据处理配方、一种正则。如果最终配方只需几个 bit 就能说清，那么模型对基准的真正依赖，远小于那份漫长蜿蜒的实验记录所暗示的。爬山走得很远，从另一头出来的东西却是——或者说本来可以是——很小的。

## [压缩、智力，以及一个懂行的听者](#compression-intelligence-and-the-power-of-a-knowledgeable-listener)

想象你要把一条具体的机器学习管线讲给一个聪明的高中生，细到他真能复现。那会是一场又长又累的谈话。你得解释什么是梯度下降、什么是神经网络、PyTorch / JAX / TensorFlow 干什么、什么是学习率，没完没了。这些几乎没有一项是你这个问题特有的；那是机器学习怎么工作的通用背景。

再想象把同一条管线讲给一位专家 ML 工程师。谈话立刻收成几句。凡是常识你都跳过，只传这个问题真正特有的东西：架构选择、batch size、优化器、两三个超参。听者对世界知道得越多，你要发的消息就越短——你就能压得越狠。这些「世界知识」在奥卡姆剃刀的论证里不算你的负担，因为你可以在看训练集之前就把它们全写下来。

大语言模型从这里进场。现代 LLM 带着海量世界知识。它们知道 ML 工具怎么用，知道标准优化算法，知道常规超参选择和常见默认值。细节没写明，它们也能补一个说得通的值。这让它们成为极好的**压缩解码器**：把一段极短的、专家对专家的消息交给 LLM，它能展开成一套完整、能跑的流程。想一想，这正是它们如此强大的原因。

## [实验：把策略挤过瓶颈](#the-experiment-squeezing-a-strategy-through-a-bottleneck)

这提示了一个干净的实验。让一个 ML 研究 agent——**explorer**——去解一个新的机器学习问题。给它完整的验证集访问权，让它自由实验、迭代，几百轮地追更好的验证表现。这里验证集扮演基准的角色：一个 agent 可以一遍遍查询的**可复用 holdout**。这就是理应过拟合的爬山回路。

然后测解有多可压缩。第二个 agent，**compressor**，读完 explorer 的全部工作记录，试图把获胜策略蒸馏成极短的提示——就一把 token。这份提示交给第三个 agent，**reproducer**，它必须只凭提示和训练数据从零实现策略。关键是：reproducer **不能**访问验证集、explorer 的代码或记录。短提示是验证集里学到的任何东西能到达它的唯一通道。（我们论文里报告的研究中，compressor 和 reproducer 都是 Claude 模型。）

如果 reproducer——冷启动、手里只有几个 token——能追上 explorer 的表现，那么指定该策略所需的、依赖验证集的全部信息，都挤过了那条细通道。策略是可压缩的。我们称之为**输出压缩（output compression）**证书。

这套设置有一个人类研究社区没有的好性质：reproducer 可以一遍遍重置。compressor 可以试很多种压缩，看每一种解码得怎样，因为每次尝试都落在一个对新一轮没有记忆的全新 reproducer 上。有点像电影《Memento》——你在给一个读条之前记忆会被抹掉的自己留一张极短的纸条。你得学会写那种「懂行但失忆的副本」能照着干的条子；条子可以很短，因为接收方会把你没写的东西，按你会写的方式补上。

![explorer 的策略被挤过狭窄信息瓶颈的示意图](https://cdn.amazon.science/ac/bd/b0c9558b4052a883f75e6d2f47f3/compressionmodels-04-1x1.png)

在研究者的实验里，explorer agent 的策略被挤过狭窄的信息瓶颈。能在压缩里活下来的，必须反映真实结构，而不是记下来的数据。

## [从另一头出来的是什么](#what-comes-out-the-other-end)

压缩结果出奇地小。横跨八个数据集——表格分类、图像分类、语言建模、扩散建模、奖励建模——32 个 token 的提示，就够一个全新的 reproducer 在绝大多数问题上追上 explorer 自适应优化出来的模型。有一条语言建模策略压到只有 16 个 token，留出集表现仍不掉。

这些提示实际长什么样？最说明问题的例子，正好卡在压缩快要断掉的简洁边界上。在一次语言建模实验里，explorer 发现了一套定制的 GPT 风格训练配方。16 个 token 的预算下，这仍够全新 reproducer 追上未压缩的 explorer：

**QKn 12L768 Mu .1 R² b2M 4x**

对人来说这像密码，对另一个 ML agent 却是具体指令：*QKn* 是 QK normalization，*12L768* 是 12 层、768 维的 Transformer，*Mu .1* 是 Muon 优化器、学习率 0.1，*R²* 是 squared-ReLU 激活，*b2M* 是两百万 token 的 batch，*4x* 是四倍宽的前馈块。把预算砍到八个 token，提示变成：

**12L768 Mu .1 R²**

这时 reproducer 就追不上 explorer 了。缺掉的片段指定的是真正依赖数据、跟最显然的默认值不同的训练选择。这条边界标出了可压缩性的限度，而且很重要。它说明 reproducer 并不是单靠先验知识就成功。少数被压缩的 token 带着从数据本身学到的真信息；这些 token 一消失，成绩也消失。

我们还做了一组从另一个方向施加信息瓶颈的实验。不是压缩 explorer 的**输出**，而是压缩它的**输入**：不告诉 explorer 每个模型的数值验证分数，只回一个 bit——这个模型有没有超过当前最优？即便每次查询只剩 1 bit 反馈，explorer 找到的策略仍跟拿到完整数值分数时一样好。验证集到最终策略之间的通道两边都窄，而且 1 bit 版本还带有严格的泛化数学保证。

[原文短视频](https://cdn.amazon.science/18/ff/a70ce9fd4f878910640f3d0afeaa/compressionmodels-02-16x9.mp4)

![八个数据集上，几百轮迭代得到的策略可压到 16–32 个 token](https://raw.githubusercontent.com/lihenair/techtranslate/master/assets/Why-dont-machine-learning-research-agents-overfit/video-2.gif)

横跨八个数据集，从几百轮迭代实验里长出来的策略，能压进短到 16 到 32 个 token 的提示——短到一个没有记忆的新 agent 也能复现原来的结果。

## [抓住作弊的](#catching-cheaters)

好的经验理论应当可证伪——这一套也是。如果低过拟合真的由可压缩性解释，那么真正过拟合的模型就应该没法沿这条管线被压缩。

为了检查，我们故意把 agent 推进过拟合：直接给它们验证集访问权，并提示它们不惜一切最大化验证表现。Agent 上钩了：102 次实验运行里，有 38 次验证准确率比真正的留出准确率高出 10% 以上。

理论预测这些增益过不了压缩瓶颈，因为它们编码的是特定验证样本的癖好，不是可迁移的结构。果然，挤过短提示交给全新 reproducer 之后，那些只对验证集有效的优势消失了。压缩以很高的准确率把正当策略和过拟合策略分开。

所以压缩不只解释了自主研究 agent 为何往往不过拟合，还提供了一个抓住过拟合的工具：标出那些没有任何短描述能复现结果的情形。

## [这告诉我们什么——以及没告诉什么](#what-this-tells-us-and-what-it-doesnt)

几条 caveat 得先说清。整套框架假定：从验证数据到最终模型的唯一路径，就是我们喂给 reproducer 的那条提示。当然，如果一个模型在预训练时就把验证数据背下来了，它会有一条绕过我们想施加的信息瓶颈的旁路。我们不认为实验里发生了这种事：agent 是通过真实搜索逐渐变好，而不是一开始就站在最好处；token 预算极短时成绩会掉。但要把这个问题彻底说清，大概还需要用模型训练截止日期之后采集的新鲜数据集做实验，我们还没做。

最重要的是：我们的结果说的是 LLM agent，因为只有那里实验才可能——你可以重置被试、控制输入、数它们的长度。但它们画出的图景，对人类研究社区也很有暗示。当一个领域花几年爬一座固定基准，增益还不断转移到新鲜数据上，原因可能跟 agent 的策略能活过 32 个 token 的提示一样：真正管用的配方是简单的。或者换句话：「What fits (into few tokens) doesn't overfit.」
